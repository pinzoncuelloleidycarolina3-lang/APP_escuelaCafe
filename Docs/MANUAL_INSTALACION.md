# Manual de Instalación - Escuela Café

Este manual describe los pasos exactos para desplegar el proyecto **Escuela Café** desde cero en un entorno local (Windows/Mac/Linux).

## Requisitos Previos
- Tener instalado **Node.js** (v18 o superior).
- Tener una cuenta en **MongoDB Atlas** (Base de datos).
- Tener instalado **Git**.

## Paso 1: Clonar el repositorio
Abre una terminal y ejecuta:
```bash
git clone https://github.com/pinzoncuelloleidycarolina3-lang/APP_escuelaCafe.git
cd APP_escuelaCafe
